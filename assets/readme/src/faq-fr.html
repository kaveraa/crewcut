Trois questions qui méritent une réponse.

Pourquoi un plugin quand un prompt de sept mots coupe autant sur Opus ?Le prompt coupe à l'aveugle. Il saute les tests, écrit plus de code que pas de prompt sur Haiku, et retire une fois le contrôle par client d'un limiteur de débit. crewcut nomme ce qui n'est jamais coupé et corrige un bug à sa racine. Pour l'économie du prompt, /crewcut tests off garde tout le reste.
Suit-il les nouveaux modèles ?Oui. Le ruleset est injecté quel que soit le modèle de la session, et les deux agents nomment le leur par alias. Les chiffres sont une autre affaire : chacun vaut pour le modèle sur lequel il a été mesuré.
Revendique-t-il une économie sur mon dépôt ?Non. /crewcut-gain affiche les chiffres mesurés. La version que vous n'avez pas construite n'a jamais été écrite.
