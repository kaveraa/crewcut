Levels and commands

Four levels, one command to switch.

offNothing, for this session
liteOutput discipline, light reading habit
fullDefault. Output, reading, writing, tools
ultraFull, plus one-line answers, no new file unasked
/crewcut <level>switch level; alone, show the current one
/crewcut default <level>level new sessions start at
/crewcut tests on|offoff: a test only when the ticket asks
/crewcut map on|offthe project's names and versions at session start
/crewcut subagents on|offthe rules in subagents too
/crewcut lang <code>reply in en, es, fr, de, ko or zh
/crewcut markers on|offa discreet // ~ comment on a cut corner
/crewcut-review [scope]read-only review of a change
/crewcut-audit [path]the same over a whole tree, ranked
/crewcut-debt [path]ledger of the // ~ markers
/crewcut-gainthe measured figures, as a card
/crewcut-helpreference card
/crewcut uninstallremove the plugin's files next to your settings
