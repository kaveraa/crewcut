/crewcut-review, un exemple du format

Relu comme le senior qu'on appelle quand ça casse.

What this does: adds a nightly job that closes the day and bills its orders. Must fix 1. Orders land on the wrong day (billing/close_day.py:40-52) What: the job stamps each order with the server clock, which runs in UTC. Problem: an order placed at 00:30 in Berlin is billed on the day before. Fix: take the date once in the shop's time zone; one line. If skipped: late orders carry the wrong date, fixed by hand. Should fix 2. No test on the billing total (billing/close_day.py:60) Verdict: fix 1 first. cut: 14 lines
Dans l'ordre : juste, sûr, tient à la charge, testé, rapide, sobre. Lecture seule.
