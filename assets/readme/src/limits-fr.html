Limites

Ce qu'il ne fait pas, dit simplement.

Node dans le PATHLes hooks ont besoin de node. Sans lui, seuls les skills fonctionnent.
Un niveau par projetDeux sessions dans le même projet le partagent. La ligne de statut affiche le dernier niveau posé, quel que soit le projet.
Une carte par regexLes définitions de premier niveau dans dix langages ; les imbriquées ou dynamiques n'y sont pas. Versions lues dans package.json et composer.json seulement.
Claude Code seulementHooks, niveaux, revue, audit et registre. Les autres agents reçoivent le ruleset par AGENTS.md.
Pas en session cloudclaude.ai/code ne charge pas un plugin installé avec /plugin. L'installation de crewcut y est en cours de test.
