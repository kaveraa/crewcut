Niveaux et commandes

Quatre niveaux, une commande pour en changer.

offRien, pour cette session
liteDiscipline de sortie, lecture légère
fullPar défaut. Sortie, lecture, écriture, outils
ultraFull, plus des réponses d'une ligne, aucun fichier non demandé
/crewcut <niveau>change de niveau ; seul, affiche le niveau courant
/crewcut default <niveau>niveau de départ des nouvelles sessions
/crewcut tests on|offoff : un test seulement si le ticket le demande
/crewcut map on|offles noms et les versions du projet au démarrage
/crewcut subagents on|offles règles dans les sous-agents aussi
/crewcut lang <code>répond en en, es, fr, de, ko ou zh
/crewcut markers on|offun commentaire discret // ~ sur un coin coupé
/crewcut-review [portée]revue en lecture seule d'un changement
/crewcut-audit [chemin]la même sur tout un arbre, classée
/crewcut-debt [chemin]registre des marqueurs // ~
/crewcut-gainles chiffres mesurés, sous forme de carte
/crewcut-helpcarte de référence
/crewcut uninstallretire les fichiers du plugin à côté de vos réglages
