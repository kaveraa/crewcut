How it works

Read what the change touches, then take the lowest rung that holds.

  1. 1Not needed?skip it, say so in one line
  2. 2Already in this codebase?reuse it
  3. 3In the standard library?use it
  4. 4Native to the platform?HTML, CSS, SQL, the OS
  5. 5An installed dependency?use it, never add one
  6. 6One line?one line
  7. 7Else the minimum that works
Never cut: trust-boundary validation, data-loss handling, security, accessibility, existing tests.
