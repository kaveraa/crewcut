Le ruleset, à chaque démarrage de session

Un senior qui lit tout et n'écrit presque rien.

Le ticket, rien de plusAucune prop, aucun état, mode ou cas limite qu'il n'a pas nommé. Un second cas d'usage est un second ticket.
Corriger la causeTrouver tous les appelants, corriger la fonction partagée une fois, même si les autres semblent sûrs.
Court ne veut pas dire fauxUne question reçoit une réponse complète. Un test qui échoue est corrigé et relancé.
Pratiques à jourSuivre ce que la documentation officielle des versions installées recommande aujourd'hui. Un doute : la lire.
Sortie propreLes commentaires disent le pourquoi, en une ligne. Ni emoji, ni flèche, ni tiret long. Aucune trace d'IA dans les commits.
Avec lui : une carte des noms que le projet définit déjà, et les versions qu'il déclare,
pour réutiliser et écrire pour la bonne version sans aucune recherche.
