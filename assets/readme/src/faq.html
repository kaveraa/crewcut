FAQ

Three questions worth asking.

Why a plugin when a seven-word prompt cuts as much on Opus?The prompt cuts blind. It skips the tests, writes more code than no prompt on Haiku, and once drops the per-client check of a rate limiter. crewcut names what never gets cut and fixes a bug at its root. For the prompt's savings, /crewcut tests off keeps everything else.
Does it follow new models?Yes. The ruleset is injected whatever the model of the session, and the two agents name theirs by alias. The figures are another matter: each one holds for the model it was measured on.
Does it claim a saving on my repository?No. /crewcut-gain prints the measured figures. The version you did not build was never written.
